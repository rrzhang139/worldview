# Briefs

Weekly synthesis briefs. One file per week, named `YYYY-Www-brief.md` (ISO week number).

The brief is the user-facing artifact of the weekly process. Each brief:

- Picks 3-5 top developments only — synthesis, not summary.
- Explicitly references which theme question each development updates.
- Flags any "would-change-my-mind" triggers loudly with ⚠️.
- Stays under 2 pages. If you need more, you're summarizing instead of synthesizing.

The detailed log entries live in `themes/*.md`, not here. The brief is the index into that week's logs.

See `TEMPLATE.md` for the structure.
